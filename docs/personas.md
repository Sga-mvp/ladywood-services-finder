# Personas

*To be drafted.*

This document will hold 3–4 personas covering the user archetypes identified
in `problem-statement.md`:

1. An older resident post-library-closure (primary)
2. A family-in-poverty resident needing time-sensitive help (primary)
3. A recent migrant or non-English-first-language resident (primary)
4. A voluntary-sector org admin (secondary stakeholder)

Each persona will include: name, age, situation, goals, frustrations, tech
context (device, connectivity, literacy), and a representative "day in which
they would use the system" vignette.
